Number formats

One reference. Every number on every screen is one of these.
Format
Display
Rule
Spread
OSU −27.5BSU −10PK
Favorite’s abbr + U+2212. Half points as .5, whole numbers bare. Even line = PK. No line = “No line” in muted.
Price
−110
American odds, always signed. Muted 12px when shown beside a spread.
Model line
OSU −31.2CLEM −34.0
Same as spread, but always one decimal, so model and market never look alike.
Edge
+3.7 OSU+0.6 UTAH
Always “+”, one decimal, side after. Filled pill only when ≥ 2.5 (a pick); otherwise plain muted text.
Cover %
59%~54%
Integer for the edge side. “~” prefix = market-implied (no model yet).
Win %
TEX 54%
Model favorite’s abbr + integer %. Record win rates use one decimal: 56.4%.
Rating
+27.4
Signed, one decimal, ink color. Call · “+” means above average, not good news, so ratings take no color.
Rank move
▲3▼1—
Triangle + places. Em dash for no change. Shape carries it; color confirms.
Record
31-24-15-0
W-L-P with hyphens. Push count only when non-zero.
Units
+4.6u−1.1u
Signed, one decimal, “u” suffix with no space. Pos/neg color + sign.
CLV
+0.9 pts
Signed, one decimal, “pts”. Positive = beat the closing number.
Kickoff
Sat 3:30 PM ETCBS
Day · time · ET. “ET” drops inside tables where the column header says ET. Network muted.
Lock countdown
Locks in 1d 14hLocked
Two largest units only (1d 14h, 3h 20m, 12m). Becomes “Locked” + lock icon at kickoff.
Live score
PUR 3 · OSU 24Q3 9:12
Plex Mono. Away first, matching “away @ home” rows. Live dot + quarter + clock; never the dot alone. Final: “Final · UNLV 24, BSU 31”.
